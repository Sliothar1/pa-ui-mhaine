# Accessibility gates (PA Uí Mhaine)

CI (`site-checks`) runs:
- `tools/a11y_check.py a11y.json` (static, fails CI on FAIL): WCAG AA contrast of each text/accent
  token on each surface in light and dark (C1; `warn`/`focus` held to 3:1 as UI colours); skip link
  is the first link and its target exists on every page (C2); CSS motion has a
  `prefers-reduced-motion` override (C3); `<html lang="en">` (C4); `lang="ga"` heuristic for Irish
  text outside a `lang="ga"` element (C5, warning only); non-map list view per map page (C6).
- `tests/run_tests.py` (Playwright): axe-core on every page in both themes (T14), focus contrast (T16), and the rest.

Non-map equivalents: index.html map → the scene list (`#sc-h`) and "Read the journey" text;
timeslider.html map → the twelve-stop list (`#stoplist`) and the route list (`#routelist`).

Open warnings (11 Oct 2026): C5 lists Irish names (Ó Dubhagáin, Ó Dálaigh, Dún, Mór, nÉigeas,
Ériu, pailís, Áed, Bórama…) in English sentences without `lang="ga"`. WCAG 3.1.2 exempts proper
names, so these are editorial calls for Garry, not failures. Manual before release: keyboard-only map
walk (fly-through controls, Esc exits show mode, time slider by arrow keys), a screen reader pass,
200% zoom, 320 px.
